# Yeni Gençlik Buca — GitHub Pages

## Dosyalar
- `index.html`: Mobil uyumlu sosyal medya bağlantı sayfası
- `logo.jpg`: Gönderdiğiniz logo

## Ücretsiz yayınlama
1. GitHub hesabınızda **New repository** seçeneğiyle `yeni-genclik-buca` adında bir repository oluşturun.
2. Bu ZIP içindeki `index.html` ve `logo.jpg` dosyalarını repository'nin ana dizinine yükleyin.
3. Repository > **Settings** > **Pages** bölümüne girin.
4. **Deploy from a branch** seçin; branch `main`, klasör `/ (root)` olsun ve kaydedin.
5. GitHub Pages yayın adresi genellikle `https://KULLANICI-ADINIZ.github.io/yeni-genclik-buca/` biçiminde olur.

QR kodu gerçek sayfa adresi yayınlandıktan sonra o kesin URL'ye göre oluşturulmalıdır. Böylece QR doğru sayfayı açar.
